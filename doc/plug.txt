==============================================================================
OVERVIEW                                                           *vim9-plug*

vim9-plug is a single-file Vim plugin manager based on vim-plug 0.15.0.
It requires Vim 9.1 or later with Vim9 script support and Git.

Copy autoload/plug.vim into the autoload directory on your runtimepath.
Add this to your Vim9 configuration: >

    vim9script

    import autoload 'plug.vim' as plug

    if plug.Begin()
      plug.Add('tpope/vim-sensible')
      plug.End()
    endif
<
Run :PlugInstall to install declared plugins. To use this help file, put
it in doc/ on your runtimepath and run :helptags ALL. See |plug-migration|
for migration from vim-plug or earlier vim9-plug releases.

==============================================================================
VIM9 MODULE                                                  *plug-functions*

The examples use the namespace "plug" from: >

    import autoload 'plug.vim' as plug
<
                                                               *plug.Begin()*
plug.Begin(directory: string = ''): bool
                Start the declaration block. An empty or omitted directory
                uses g:plug_home or the first runtimepath entry followed by
                /plugged. Returns true when the plugin home is accepted.

                                                                 *plug.Add()*
plug.Add(repository: string, options: dict<any> = {})
                Register a Git repository or an externally managed local
                plugin. A GitHub owner/repository shorthand uses
                g:plug_url_format. Pass a dictionary for options. Invalid
                declarations throw an exception. See |plug-options|.

                                                                 *plug.End()*
plug.End()      Apply runtimepath ordering, set up lazy-loading triggers,
                and enable filetype plugins and indentation. During startup,
                also enable syntax highlighting when available.

                                                                *plug.Load()*
plug.Load(names: list<string>): bool
                Load one or more named plugins, e.g. plug.Load(['one']).
                Returns true if a plugin was loaded.

                                                              *plug.Restore()*
plug.Restore(pins: dict<string>)
                Pin each named, currently managed plugin to a Git commit ID
                and force an update of those plugins, including frozen ones.
                Use a full or abbreviated hexadecimal ID (at least 4 digits).
                An invalid ID for a managed plugin throws before applying
                any pins. Unknown and locally managed names are skipped.
                An empty selection performs no update. See |:PlugSnapshot|.

                                                            *plug.Helptags()*
plug.Helptags(): bool
                Generate help tags for declared plugin directories.
                Returns true once the tag generation pass runs.

                                                         *plug.ShellEscape()*
plug.ShellEscape(arg: string [, shell: string [, for_batch: bool]]): string
                Escape an argument for a POSIX shell, cmd.exe, or PowerShell.
                The default shell is cmd.exe on Windows and sh on other
                platforms. The optional for_batch flag defaults to true and
                selects cmd.exe batch-file escaping.

==============================================================================
DECLARATION OPTIONS                                *plug-options* *PlugOptions*

Options in a dictionary:

    branch      Select a branch.
    tag         Select a tag. A wildcard selects the latest matching tag.
    commit      Select a commit.
    rtp         Plugin runtime directory relative to the repository root.
    dir         Override the plugin's installation directory.
    as          Set the name used in commands and g:plugs.
    frozen      Skip updating an installed plugin unless named explicitly.
    on          Lazy-load on a command or <Plug> mapping. Accepts a string
                or a list. An empty list allows manual loading.
    for         Lazy-load on a filetype. Accepts a string or a list.
    do          Post-update hook. A shell string runs in the plugin
                directory. A string beginning with a colon runs as a Vim
                command in Vim9 syntax. A function receives a dictionary with name,
                status (installed, updated, or unchanged), and force.

==============================================================================
COMMANDS                                                       *plug-commands*

                                                *:PlugInstall* *:PlugUpdate*
:PlugInstall[!] [name ...] [threads]    Install missing plugins.
:PlugUpdate[!] [name ...] [threads]     Install or update plugins.
                The optional thread count overrides g:plug_threads.
                --sync waits for completion in the calling script.
                A bang forces eligible post-update hooks and submodule
                updates. Vim jobs and channels enable parallel operation.

                                                                  *:PlugClean*
:PlugClean[!]   List unused directories under the plugin home and managed
                checkouts that need reinstallation. A declared plugin can
                be nested several directories deep. Review the list before
                confirming deletion. A bang skips the confirmation prompt.

                                                     *:PlugStatus* *:PlugDiff*
:PlugStatus     Show installation and loading status.
:PlugDiff       Show the last update and pending changes for pinned plugins.

                                                                *:PlugSnapshot*
:PlugSnapshot[!] [file]
                Record the checked-out revisions of installed Git plugins in a
                Vim9 script. Source it after declaring your plugins to restore
                the recorded plugins that are still managed, including frozen
                ones. A bang allows replacing an existing file.

                                                                *:PlugUpgrade*
:PlugUpgrade    Upgrade the installed script from the vim9-plug repository.
                The previous file is kept as plug.vim.old after an upgrade.

==============================================================================
CONFIGURATION                                           *plug-global-options*

*g:plug_threads*       Maximum parallel tasks. Default: 16.
*g:plug_shallow*       Use shallow clones when possible. Default: 1.
*g:plug_window*        Command to open the management pane. Default: :-tabnew.
*g:plug_pwindow*       Command to open a diff preview.
                       Default: vertical rightbelow new.
*g:plug_url_format*    URL format for subsequent GitHub shorthand declarations.
                       Default: https://git::@github.com/%s.git
*g:plug_home*          Plugin installation directory.
*g:plugs*              Dictionary of registered plugin specifications.
*g:plugs_order*        Plugin names in declaration order.
*g:plug_timeout*
*g:plug_retries*       Settings for the retired Ruby and Python backends.
                       The Vim installer does not read these settings.

==============================================================================
PANE KEYS                                                      *plug-keybindings*

  q       Close the preview or pane. Abort a running installation.
  R       Retry failed work after installation or update.
  D / S   Open the diff or status pane.
  U       Update the plugin on the current line or marked lines.
  L       Load the plugin on the current line or marked lines in status.
  ]] / [[ Jump to the next or previous plugin entry.
  o / CR  Preview a change in :PlugDiff.
  X       Revert an update in :PlugDiff after confirmation.
  d{motion}, dd
          Select directories for deletion after declining :PlugClean.

==============================================================================
MIGRATING                                                       *plug-migration*

Move the declaration block into a Vim9 vimrc or a separate Vim9 file sourced
from your vimrc. Put "vim9script" first and add the autoload import above
your declarations. Restart Vim after replacing autoload/plug.vim. Your
plugin installation directories can be reused.

    call plug#begin()           becomes  plug.Begin()
    Plug 'owner/repo'           becomes  plug.Add('owner/repo')
    call plug#end()             becomes  plug.End()
    call plug#load('one')       becomes  plug.Load(['one'])
    call plug#helptags()        becomes  plug.Helptags()

Use a dictionary for a tag, e.g. plug.Add('owner/repo', {tag: 'v1.0'}).
Convert legacy hook lambdas to (info) => Expression(info). A command hook
such as ':let g:ready = 1' becomes ':g:ready = 1'. In a custom command
string, prefix Vim9 ranges with a colon, e.g. ':-tabnew' in g:plug_window.

For complete before-and-after examples see doc/migration.md in the
vim9-plug repository.
